# Clarifications Worth Sending Before/While Building

1. When you say HR should "answer questions about how the org pays people," do you expect deterministic dashboards/filters, a natural-language AI interface, or either approach?
2. For multiple countries, should the system report compensation only in local currencies, or should it normalize to a single reporting currency? If normalized, is there an approved reporting currency/FX-source expectation?
3. Is the assessment expected to model only current base salary, or should salary revision history/variable compensation also be represented?
4. Is authentication/RBAC within assessment scope, or is a synthetic-data demo acceptable while documenting production security requirements?

These questions are intentionally narrow: they materially affect the domain model or scope. The project can progress on non-dependent scaffolding while awaiting answers.
