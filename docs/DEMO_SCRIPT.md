# 3–5 Minute Demo Script

1. **Problem & scope (30s)** — "ACME has 10,000 salaries in spreadsheets. I optimized for fast HR lookup, safe updates, migration, and explainable reporting; I deliberately did not build payroll/tax/LLM features."
2. **Dashboard (40s)** — Show employee count, normalized payroll, average/median, department and country breakdowns, distribution. Call out mixed-currency normalization.
3. **Employee directory (45s)** — Search, combine department/country/salary filters, sort, paginate. Explain server-side data access.
4. **Salary update (40s)** — Open employee, change salary, show updated normalized value and new salary-history row.
5. **CSV migration (35s)** — Show expected CSV format/import; briefly demonstrate a validation failure or successful small file.
6. **Engineering (45s)** — Show architecture/docs, seed command, representative tests, and test run.
7. **AI workflow & trade-offs (30s)** — Show `AI_USAGE.md`, rejected over-engineering, and next production steps.
